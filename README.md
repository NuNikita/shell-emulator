# Эмулятор командной строки — этап 2

Графический прототип эмулятора UNIX-подобной командной строки на Python.
Приложение поддерживает настройку через параметры командной строки и
выполнение стартового скрипта.

Команды `ls` и `cd` пока являются заглушками: они показывают своё имя и
полученные аргументы, но не работают с файловой системой. Команда `exit`
закрывает окно эмулятора.

## Возможности

- Графический интерфейс на основе `tkinter`.
- Заголовок `Эмулятор - [username@hostname]` с данными текущей ОС.
- Разбор аргументов в одинарных и двойных кавычках через `shlex`.
- Настройка расположения VFS, приглашения и стартового скрипта.
- Отладочный вывод всех параметров при запуске.
- Последовательное выполнение команд из стартового скрипта.
- Остановка стартового скрипта при первой ошибке.
- Вывод команд скрипта и результатов в виде диалога с пользователем.
- Обработка неизвестных команд и незакрытых кавычек.

## Параметры командной строки

### `--vfs`

Задаёт путь к физическому расположению виртуальной файловой системы.
На втором этапе путь выводится в отладочной информации. Работа с VFS будет
реализована на следующих этапах.

Значение по умолчанию — текущая папка:

```text
--vfs .
```

### `--prompt`

Задаёт приглашение, которое отображается рядом с полем ввода и перед
командами в истории REPL.

Значение по умолчанию:

```text
$
```

Приглашение с пробелами необходимо заключать в кавычки:

```text
--prompt "shell> "
```

### `--script`

Задаёт путь к стартовому скрипту с командами эмулятора. Если параметр не
передан, приложение запускается без выполнения скрипта.

```text
--script scripts/startup_success.txt
```

## Стартовый скрипт

Каждая непустая строка файла считается отдельной командой. Пустые строки и
строки, состоящие только из пробелов, пропускаются.

При выполнении команды на экране отображаются её текст и результат. Если
команда завершается ошибкой, выполнение скрипта останавливается и выводится
номер ошибочной строки.

Пример успешного скрипта:

```text
ls
ls "folder with spaces"
cd "virtual directory"
```

Пример скрипта с ошибкой:

```text
ls "before error"
unknown-command
cd "must not be executed"
```

Последняя команда не выполнится, потому что `unknown-command` завершится
ошибкой.

## Запуск

Требуется Python 3 с доступным модулем `tkinter`. Сторонние зависимости и
предварительная сборка не требуются.

Запуск со значениями по умолчанию:

```powershell
python main.py
```

В Windows также можно использовать:

```powershell
run.bat
```

Запуск со всеми параметрами второго этапа:

```powershell
python main.py --vfs src --prompt "shell> " `
    --script scripts/startup_success.txt
```

Просмотр справки:

```powershell
python main.py --help
```

## Системные сценарии проверки

В папке `scripts` находятся два Windows-сценария. Каждый запускает эмулятор
со всеми поддерживаемыми параметрами командной строки.

Успешное выполнение стартового скрипта:

```powershell
scripts\run_success.bat
```

Остановка стартового скрипта при ошибке:

```powershell
scripts\run_error.bat
```

## Примеры работы

```text
shell> ls "my folder" 'two words'
ls: аргументы: ['my folder', 'two words']
shell> cd "new directory"
cd: аргументы: ['new directory']
shell> unknown
unknown: команда не найдена
shell> ls "unfinished
Ошибка синтаксиса: No closing quotation
shell> exit now
exit: аргументы не поддерживаются
shell> exit
```

## Тестирование

Запуск всех автоматических тестов:

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют команды-заглушки, аргументы в кавычках, команду `exit`,
значения конфигурации и обработку некорректных параметров запуска.

## Структура проекта

- `main.py` — точка входа и разбор конфигурации.
- `src/config.py` — параметры командной строки.
- `src/gui.py` — графическое окно и выполнение стартового скрипта.
- `src/shell.py` — разбор и выполнение команд эмулятора.
- `tests/` — автоматические тесты.
- `scripts/` — стартовые и системные тестовые сценарии.
- `run.bat` — простой запуск приложения в Windows.

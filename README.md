# Эмулятор командной строки — этап 1

Графический прототип эмулятора UNIX-подобной командной строки на Python.
На этом этапе команды `ls` и `cd` являются заглушками: они показывают
своё имя и разобранные аргументы, но не обращаются к файловой системе.
Команда `exit` закрывает окно.

## Возможности

- Окно с историей ввода и вывода и строкой для ввода команд.
- Заголовок `Эмулятор - [username@hostname]` с данными текущей ОС.
- Разбор аргументов в одинарных и двойных кавычках через `shlex`.
- Сообщения о неизвестной команде, незакрытой кавычке и аргументах `exit`.
- Пустая строка принимается без ошибки.

Настроек командной строки на этапе 1 нет. Параметры запуска, стартовые
скрипты и виртуальная файловая система относятся к следующим этапам.

## Сборка и запуск

Требуется Python 3 с доступным модулем `tkinter`. Сборка и сторонние
зависимости не требуются. Из корня репозитория:

```
python main.py
```

В Windows также можно запустить `run.bat`.
Тесты:

```
python -m unittest discover -s tests -v
```

## Примеры интерактивной работы

Вводится одна команда в нижней строке окна, затем нажимается Enter:

```
$ ls
ls: аргументы: []
$ ls "my folder" 'two words'
ls: аргументы: ['my folder', 'two words']
$ cd "new directory"
cd: аргументы: ['new directory']
$ unknown
unknown: команда не найдена
$ ls "unfinished
Ошибка синтаксиса: No closing quotation
$ exit now
exit: аргументы не поддерживаются
$ exit
```

После последней команды окно закрывается. Основные сценарии проверяются
автоматическими тестами в `tests/`.

## Структура

- `main.py` — точка входа.
- `src/gui.py` — графическое окно и диалог.
- `src/shell.py` — разбор строки и команды этапа 1.
- `tests/` — автоматические проверки.
- `run.bat` — запуск в Windows.
